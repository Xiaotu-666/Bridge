# 公路桥梁初始检查信息系统 — 系统功能架构设计

## 1. 业务概述

本系统依据《JTG 5120-2021 公路桥涵养护规范》，对公路桥梁的初始检查（首次全面检测）和定期检查（周期性检查）进行信息化管理，实现桥梁基本状况卡片、初始检查记录表和定期检查记录表的电子化录入、存储、查询和统计分析。

**核心业务流程：**
```
新建/改建桥梁交付 → 初始检查(首次全面检测) → 生成桥梁基本状况卡片
                                                      ↓
                        周期性定期检查 → 填写定期检查记录表 → 技术状况评定 → 养护决策
```

## 3. 用户角色定义

| 角色 | 权限范围 | 职责描述 |
|------|---------|---------|
| **系统管理员** | 系统配置、用户管理、权限分配、数据备份 | 维护系统正常运行 |
| **桥梁工程师** | 全部业务模块读写、档案管理、评定审核 | 负责桥梁技术状况评定、检查数据审核 |
| **检测人员** | 初始检查/定期检查记录录入、查询 | 现场检测数据录入与维护 |
| **查询浏览者** | 查询统计、报表查看（只读） | 领导或外部人员查阅数据 |

## 4. 核心功能模块详细描述

### 4.1 桥梁档案管理
- **描述：** 以"一桥一档"为原则，管理桥梁全生命周期档案，基于规范的附录A桥梁基本状况卡片。
- **输入数据：** 路线编号、桥梁编号、桥梁名称、技术指标（桥长、桥宽、净空等）、结构数据（上部/下部结构形式与材料）、档案资料完整性标记。
- **输出数据：** 桥梁基本状况卡片（完整档案）、桥梁清单、分类统计报表。
- **设计流程：** 选择或新建路线 → 输入桥梁行政识别数据 → 录入技术指标 → 录入结构信息 → 管理档案资料 → 记录检测评定历史 → 保存。

### 4.2 初始检查管理
- **描述：** 基于规范附录B桥梁初始检查记录表，管理新建桥梁的首次全面检测数据。
- **输入数据：** 引用桥梁ID、路线信息、施工/设计单位、交工时间、测量数据（桥面高程22项参数）、材质强度、保护层厚度、索力、荷载试验结果等。
- **输出数据：** 初始检查记录表（完整表格）、检测参数汇总。
- **设计流程：** 选择桥梁 → 填入检查基本信息（时间、气候、机构） → 逐一录入各检测项数据 → 自动计算汇总 → 保存并关联桥梁档案。

### 4.3 定期检查管理
- **描述：** 基于规范附录C（C-1至C-6），按6种桥型分别管理周期性检查数据。
- **输入数据：** 引用桥梁ID、检查时间、气候环境、各部件评分（0-5等级）、缺损类型/位置/范围/照片、养护建议。
- **输出数据：** 定期检查记录表、桥梁技术状况评定等级、缺损汇总。
- **设计流程：** 选择桥梁 → 选择桥型模板 → 逐部件检查评分 → 记录缺损详情 → 填写养护建议 → 自动计算技术状况等级 → 保存。

### 4.4 查询统计
- **描述：** 对系统中的桥梁档案、检查记录进行多维度查询和统计分析。
- **支持维度：** 路线、桥梁名称/编号、检查类型、检查日期范围、桥梁等级、桥型、技术状况等级等。
